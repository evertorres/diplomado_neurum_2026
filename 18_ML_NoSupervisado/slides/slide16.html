Criterios de parada para algoritmo K-means

El proceso iterativo del algoritmo no es infinito. Se detiene automáticamente cuando se satisface cualquiera de las siguientes condiciones de parada:

📍

Estabilidad de Centroides

El algoritmo se detiene si la posición geográfica de los centroides no sufre ninguna modificación en el paso de recálculo (la variación es cero o inferior a una tolerancia $\epsilon$ muy pequeña).

$$\Delta \text{centroides} \le \epsilon$$
🔄

Asignación Invariable

Se detiene cuando ningún punto de datos de la muestra es reasignado a un clúster diferente en el paso de asignación. La distribución de elementos en los grupos queda completamente fija.

$$\Delta \text{asignaciones} = 0$$
⏱️

Límite de Iteraciones

Como medida preventiva de seguridad computacional, el proceso termina de forma forzada si se alcanza el número máximo de ciclos (iteraciones) configurado por el usuario (ej. 300 iteraciones).

$$\text{Iteraciones} \ge \text{max\_iter}$$
