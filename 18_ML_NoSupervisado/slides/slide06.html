El problema del clustering

Definición formal del agrupamiento de datos desde una perspectiva de particionamiento conjuntista:

📥 Entrada (Datos y Parámetros)

  • Conjunto de Documentos:
    $$D = \{d_1, d_2, d_3, \dots, d_n\}$$
  • Una medida de distancia (o métrica de similitud) bien definida para comparar cualquier par $(d_i, d_j)$.
  • Un criterio de partición que defina qué constituye un "buen" agrupamiento.

⚙️ Objetivo (Función a Computar)

Encontrar una función de asignación $\gamma$ que mapee cada documento a una etiqueta de clúster:

$$\gamma : D \rightarrow \{1, 2, \dots, K\}$$

Bajo las condiciones de que:

  • Ningún clúster final esté vacío: $\forall k \in \{1,\dots,K\}, \exists d \in D \text{ tal que } \gamma(d) = k$.
  • Se optimice el criterio de partición respecto a la similitud elegida.
