OMOP - Common Data Model (CDM)

🏗️

Estructura de Datos

Una representación relacional estandarizada (tablas y columnas) que organiza de manera sistemática los datos de diferentes fuentes.

➕
📚

Contenido (Vocabularios)

Estandarización del significado clínico usando vocabularios estándar (SNOMED, LOINC, RxNorm) integrados en el modelo.

Permite la investigación cruzando fuentes de datos heterogéneas sin necesidad de modificar el código analítico para cada fuente.
