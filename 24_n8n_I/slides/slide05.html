Diapositiva 04 / Módulo 24 El Ciclo Cognitivo

Razonamiento, Planificación y Autocorrección

El patrón ReAct (Reasoning + Acting) y la autorreflexión autónoma ante errores.

1. El Ciclo ReAct

Alterna iterativamente Razonamiento (Thought) ➔ Acción (Tool Call) ➔ Observación (Result). Evalúa en tiempo real el impacto de cada paso.

2. Metodologías de Planificación

Chain-of-Thought (CoT): Desglose secuencial paso a paso.
Tree-of-Thoughts (ToT): Exploración de múltiples rutas de solución alternativas.

3. Marco de Autorreflexión (Reflexion)

Al detectar un fallo externo (ej: API caída o formato inesperado), analiza la causa raíz, reformula las entradas y reintenta autónomamente.

Bucle Interactivo ReAct + Reflexion

El agente itera hasta alcanzar la respuesta validada sin requerir intervención humana.
