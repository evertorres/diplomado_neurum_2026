Procesamiento de Autorización Médica

Comparativa directa de cómo reaccionan un Bot de RPA tradicional y un Agente de APA ante una variación operacional en un sistema de salud:

🤖 Bot de RPA (Determinista)

  • Acción: Busca el botón "Adjuntar Historia" en la coord (X:450, Y:300).
  • Incidente: El software del hospital actualizó la interfaz y movió el botón.
  • Resultado: Falla crítica (Timeout Exception). El flujo se detiene y requiere programador.

🧠 Agente APA (Adaptativo)

  • Acción: Comprende el objetivo semántico: "Cargar resumen de historia clínica".
  • Incidente: Inspecciona el DOM / API de la nueva pantalla.
  • Resultado: Autocorrección exitosa. Identifica el nuevo control y completa el envío sin interrupción.
Traza de Ejecución

Ciclo ReAct (Reasoning + Acting)

Ejemplo de cómo un agente analiza un resumen de alta médica para derivar una alerta domiciliaria:

[Thought 1] El usuario solicita verificar si el paciente Juan Pérez requiere oxigenoterapia domiciliaria. [Action 1] call_tool: consultar_historia_clinica({"paciente_id": "84920"}) [Observation 1] Historia clínica recuperada: "Paciente masculino de 68 años con EPOC descompensado. Saturación al alta: 88% aire ambiente." [Thought 2] La saturación es de 88%, por debajo del umbral estándar del 90%. Debo validar el protocolo de neumología para oxigenoterapia. [Action 2] call_tool: buscar_protocolo_guia({"diagnostico": "EPOC", "sat_o2": 88}) [Observation 2] Guía clínica: Pacientes con SatO2 < 89% en aire ambiente califican para concentrador de O2 a 2L/min. [Thought 3] Se cumple el criterio. Debo preparar la solicitud de concentrador de oxígeno y notificar a la EPS. [Action 3] call_tool: crear_orden_insumo({"insumo": "Concentrador O2", "prioridad": "Alta"}) [Observation 3] Orden #ORD-9921 enviada exitosamente con aprobación directa. [Final Answer] Se ha validado la indicación médica y se emitió la orden #ORD-9921 para concentrador de oxígeno domiciliario a 2L/min.
Estándar Abierto

Model Context Protocol (MCP)

El Model Context Protocol (MCP) propuesto por Anthropic en 2024 y adoptado globalmente actúa como el "USB-C para agentes de IA".

  • Servidores MCP: Exponen recursos, herramientas y prompts estandarizados (ej: conector Postgres, FHIR Server, GitHub).
  • Clientes MCP: Los agentes o LLMs (Claude Code, n8n, LangChain) consumen las herramientas sin necesidad de conectores propietarios a medida.
  • Seguridad: Autenticación centralizada y control explícito de permisos por herramienta invocada.

¿Por qué n8n para Automatización Agéntica?

n8n trasciende la automatización de workflows tradicional al incorporar nodos de AI Agents, Memory, Tools y Vector Stores nativos.

Ventajas Clave de n8n:

  1. Visual & Low-Code: Permite diseñar y auditar flujos agénticos complejos de forma gráfica.

  3. Self-Hosted & Privado: Crucial para sector salud cumpliendo regulaciones HIPAA / GDPR sobre datos de pacientes.
