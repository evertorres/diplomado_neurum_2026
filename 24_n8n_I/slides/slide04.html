Definición y Módulos Core de APA

Mientras que a RPA le dices "cómo" ejecutar cada paso, a APA le entregas el objetivo final.

🧠

1. Agent Core

El LLM principal que actúa como controlador cognitivo, procesando intenciones y lógica contextual.

💾

2. Memoria

Corto plazo: Contexto en el prompt.
Largo plazo: Almacenamiento vectorial (MIPS/RAG) de guías y antecedentes.

🧭

3. Planificación

Descomposición de metas complejas en sub-tareas operativas y evaluación crítica de avance.

🛠️

4. Tool Use

Invocación estructurada de APIs, SQL, ejecutores de código, servidores FHIR o bots de RPA existentes.
