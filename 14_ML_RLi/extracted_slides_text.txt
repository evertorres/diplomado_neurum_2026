2. Error function: Cómo decimos que nuestro modelo está haciendo buenas predicciones?
Introducción a la Función de Costo en Regresión Lineal:
Definición: La función de costo, también conocida como función de pérdida, es una medida que indica qué tan lejos están las predicciones del modelo respecto a los valores reales. El objetivo del modelo es minimizar esta función para mejorar la precisión.
Uso en Machine Learning: En regresión lineal, la función de costo es fundamental para entrenar el modelo, ya que guía el proceso de ajuste para encontrar la mejor línea de regresión.
Tipos Comunes de Funciones de Costo:
Error Cuadrático Medio (MSE): Esta función de costo calcula el promedio de los errores al cuadrado entre las predicciones y los valores reales. La fórmula es MSE = 1/n * sum_{i=1}^n (y_i - \hat{y}_i)^2, donde y_i son los valores reales y \hat{y}_i las predicciones.
Error Absoluto Medio (MAE): Mide el promedio de las diferencias absolutas entre las predicciones y los valores reales. Menos sensible a outliers, pero puede ser menos precisa en general.
Otras Funciones de Costo: Existen funciones más complejas, pero MSE es la más común en regresión lineal debido a su sencillez y eficiencia.
Importancia de la Función de Costo:
Optimización del Modelo: El proceso de entrenamiento busca minimizar la función de costo para encontrar los mejores valores para la pendiente y el término de sesgo.
Retroalimentación para el Modelo: La función de costo proporciona retroalimentación durante el entrenamiento, permitiendo ajustar parámetros para mejorar el rendimiento del modelo.
Relación con el Gradiente: En modelos de regresión lineal, la función de costo se usa para calcular el gradiente, que indica la dirección y magnitud de los cambios necesarios para minimizar el error.

Slide 11: Error Cuadrático Medio (MSE)
============================================================
[Slide Text Content]
Error Cuadrático Medio (MSE)
Es equivalente a la distancia Euclidiana entre las predicciones y los objetivos
Se requiere de un algoritmo que mejore los pesos de forma que disminuya el MSE
Quadratics: Graphing Parabolas | SparkNotes

[Speaker Notes]
Definición de MSE: El Error Cuadrático Medio (Mean Squared Error, MSE) es una función de costo que mide el promedio de los errores al cuadrado entre las predicciones de un modelo y los valores reales. Se usa comúnmente en regresión lineal para cuantificar el error total del modelo.
Características del MSE:
Sensibilidad a Outliers: Al elevar al cuadrado los errores, el MSE es sensible a valores atípicos. Los errores grandes tienen un impacto desproporcionado en el MSE.
Uso en Optimización: El MSE se utiliza para optimizar modelos de regresión lineal, buscando minimizar el error total. Este proceso se lleva a cabo con técnicas como el descenso de gradiente.
Importancia del Cuadrado: Al cuadrar las diferencias, el MSE elimina signos negativos y enfatiza errores más grandes, ayudando a identificar problemas significativos en el modelo.
Aplicación del MSE en Regresión Lineal:
Evaluación del Modelo: El MSE se usa para medir el rendimiento del modelo durante el entrenamiento y la validación. Un MSE más bajo indica un modelo más preciso.
Ajuste del Modelo: Al minimizar el MSE, se ajustan parámetros como la pendiente y el término de sesgo para reducir el error entre predicciones y valores reales.
Comparación de Modelos: El MSE puede ser utilizado para comparar diferentes modelos o enfoques, eligiendo el que tenga el menor error cuadrático medio.
