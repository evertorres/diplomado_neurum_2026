La Ecuación del Modelo Lineal

La predicción del modelo es la suma ponderada de las características de entrada multiplicadas por sus respectivos pesos ($\theta$).

$$h_\theta(x) = \theta_0 + \theta_1 x_1 + \theta_2 x_2 + \dots + \theta_n x_n$$

De forma compacta y utilizando álgebra lineal, podemos representarlo como el producto punto de dos vectores:

$$h_\theta(x) = \theta^T x$$
Vector de parámetros ($\theta$):
Contiene todos los pesos aprendidos más el término de sesgo (bias): $[\theta_0, \theta_1, \dots, \theta_n]$
Vector de características ($x$):
Las variables de entrada correspondientes a una muestra o paciente: $[1, x_1, x_2, \dots, x_n]$
