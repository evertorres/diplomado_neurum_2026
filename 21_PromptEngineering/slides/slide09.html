El Desafío del Texto Libre en Producción

Procesar respuestas en lenguaje natural con expresiones regulares o cadenas de texto es frágil e inestable en sistemas reales.

Structured Outputs Nativos

Las APIs modernas permiten pasar un esquema JSON o clase de Pydantic. El decodificador del modelo fuerza gramaticalmente a que los tokens generados cumplan con la sintaxis del esquema sin errores de sintaxis.

# Definición del esquema con Pydantic en Python
from pydantic import BaseModel, Field
from typing import List, Optional

class DiagnosticoExtraido(BaseModel):
    paciente_id: str = Field(description="ID del paciente")
    sintomas_clave: List[str]
    severidad: str = Field(description="Leve, Moderado o Grave")
    tratamiento_sugerido: Optional[str]

# Llamada al API forzando respuesta estructurada
response = client.chat.completions.create(
    model="gemini-2.5-flash",
    response_format=DiagnosticoExtraido,
    messages=[...]
)
