Las 4 Estrategias Principales de Context Engineering

Diapositiva 22 / 26
✍️ Memoria

1. Escribir (Write)

Guardar memoria intermedia a corto o largo plazo utilizando Scratchpads, notas de trabajo o almacenes de estado de la sesión.

Ejemplo: Notas del Agente en ejecución
🔍 RAG

2. Seleccionar (Select)

Recuperar únicamente los datos relevantes del dominio mediante Búsqueda Vectorial (RAG) o bases de conocimiento externas.

Ejemplo: Chunks relevantes de PubMed
📦 Eficiencia

3. Comprimir (Compress)

Resumir historiales conversacionales largos o condensar contextos para mantener baja la latencia y ahorrar tokens.

Ejemplo: Resumen acumulado de chat
🧩 Sub-Agentes

4. Aislar (Isolate)

Dividir tareas complejas entre múltiples sub-Agentes especializados con contextos limpios e independientes.

Ejemplo: Agente Med + Agente Code
