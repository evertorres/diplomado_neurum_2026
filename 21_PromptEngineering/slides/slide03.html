Anatomía y Componentes de un Prompt

Diapositiva 03 / 26

1. Instrucción (Instruction)

Obligatorio

La tarea concreta u orden explícita que debe ejecutar el LLM (ej. "Extrae los síntomas clave").

2. Contexto (Context)

Recomendado

Información de fondo, restricciones de dominio o rol asignado para dirigir la respuesta.

3. Datos de Entrada (Input Data)

Variable

El texto, documento o datos que el modelo debe procesar o transformar.

4. Indicador de Salida (Output Schema)

Formato

El formato deseado (JSON, Markdown, tabla) e instrucciones de estilo.

Ejemplo Estructurado:
<system_role>
Eres un asistente de investigación clínica especializado en neurología.
</system_role>

<context>
Analizas notas de evolución de pacientes con migraña crónica.
</context>

<instruction>
Identifica el tratamiento prescrito y la frecuencia de las crisis.
</instruction>

<input_data>
"Paciente refiere 4 episodios por semana, trata con triptanes sin mejoría completa..."
</input_data>

<output_format>
Responde únicamente en un objeto JSON con las claves: ["tratamiento", "frecuencia_semanal"].
</output_format>
