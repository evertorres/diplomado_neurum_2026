Formateo de Entradas: Markdown y Etiquetas XML

Diapositiva 05 / 25

¿Por qué etiquetas XML y Markdown?

Los LLMs de última generación (Claude 3.5, Gemini 1.5/2.0, GPT-4o) han sido entrenados extensivamente con etiquetas XML (<context>, <examples>) y código Markdown. Las reconocen de forma nativa para segmentar la atención.

Beneficios Principales

  • Separa estrictamente instrucciones, datos y restricciones.
  • Permite referenciar secciones (ej. "Analiza únicamente el contenido dentro de <historial>").
  • Previene confusiones en textos largos con múltiples párrafos.
// Ejemplo de plantilla de prompt con XML tags

<system_instructions>
# Rol y Objetivo
Eres un asistente de triage de urgencias. Clasifica la gravedad del paciente.
</system_instructions>

<rules>
- Nivel 1: Emergencia vital inmediata.
- Nivel 2: Muy urgente.
- Nivel 3: Urgencia relativa.
</rules>

<patient_report>
Dolor torácico opresivo de 30 minutos de evolución, diaforesis, PA 150/90.
</patient_report>

<output_format>
Devuelve únicamente: Nivel | Criterio de Selección.
</output_format>
