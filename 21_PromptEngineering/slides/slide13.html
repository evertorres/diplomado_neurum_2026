¿Qué es Tree-of-Thoughts? (Yao et al., 2023)

Generaliza Chain-of-Thought permitiendo al LLM explorar múltiples ramas de solución simultáneamente como un árbol de decisión. El modelo evalúa estados intermedios y puede hacer backtracking si una rama es inviable.

Componentes Fundamentales de ToT

  • Decomposición de Pensamientos: Generar varias hipótesis o pasos independientes.
  • Evaluador de Estados: El LLM puntúa cada rama (ej. "Seguro", "Posible", "Imposible").
  • Algoritmo de Búsqueda: BFS (Breadth-First Search) o DFS (Depth-First Search).
