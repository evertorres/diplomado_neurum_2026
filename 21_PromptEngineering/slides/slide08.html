System Prompts, Personas y Asignación de Roles

Diapositiva 08 / 26

¿Qué es el System Prompt?

Es el canal de instrucciones primario del modelo. Define la personalidad, el alcance de conocimiento, las fronteras de seguridad y las restricciones globales de la sesión.

Efecto de la Asignación de Roles ("Personas")

Instruir al modelo con "Eres un epidemiólogo sénior con 20 años de experiencia" sesga el espacio de probabilidades del modelo hacia vocabulario técnico especializado, rigurosidad académica y mejor calidad de respuesta.

// Ejemplo de System Prompt en API (Gemini/OpenAI)

system_instruction = """
# ROL: Asistente de Investigación Biomédica.
# AUDIENCIA: Profesionales de la salud.
# TONO: Objetivo, técnico, basado en evidencia.
# RESTRICCIONES:
1. No emitas diagnósticos médicos a pacientes.
2. Si la consulta involucra dosis de fármacos, cita siempre la fuente bibliográfica.
3. Si la evidencia es insuficiente, indícalo expresamente.
"""
