Evaluación & Benchmarking de Prompts (Evals)

Diapositiva 20 / 26
🧪

1. Conjuntos de Prueba (Eval Sets)

Crear un conjunto representativo de 50-100 casos reales con sus respuestas esperadas (Ground Truth) para auditar cambios en los prompts.

⚖️

2. Pattern LLM-as-a-Judge

Utilizar un modelo superior (ej. Gemini 1.5 Pro / GPT-4o) con rúbricas de evaluación rigurosas para calificar automáticamente la respuesta del prompt en producción.

📊

3. Métricas RAGAS

Exactitud JSON: % de respuestas parseables.
Fidelidad (Faithfulness): Ausencia de alucinación.
Relevancia de Respuesta: Ajuste a la consulta.
🔗 RAGAS Framework

📈 Regla de Desarrollo: "Prompt Engineering is Software Engineering"

Cualquier modificación a un prompt debe pasar por integración continua (CI/CD) evaluando el Eval Set para evitar regresiones.
