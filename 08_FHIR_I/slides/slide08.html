¿Qué es un Recurso?

Un recurso es un registro de información sobre un concepto particular de salud que se puede usar para reportar y/o intercambiar datos administrativos y clínicos.

📝 Representación

El conjunto de atributos o elementos de datos tiene una forma estandarizada de representarse serializada (Ejemplo: formato JSON o XML).

"resourceType": "AllergyIntolerance",
"clinicalStatus": { ... },
"category": [ "medication" ]

🔗 Identificación

Cada recurso tiene una forma única de identificarse para ser accesible mediante una arquitectura API RESTful usando un endpoint específico.

http://127.0.0.1/fhir/AllergyIntolerance/3b77ac45-76af-42a2-b2e8-bac0792d0eb6
