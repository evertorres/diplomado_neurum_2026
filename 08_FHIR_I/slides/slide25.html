Persistencia y Bases de Datos

FHIR no solo se usa en tránsito para el intercambio de mensajes. Su estructura nativa en JSON o XML lo hace óptimo para integrarse con distintos motores de bases de datos modernas orientadas a documentos NoSQL o arquitecturas de grafo.

☁️

Amazon DynamoDB

Almacenamiento NoSQL altamente escalable clave-valor.

🍃

MongoDB

Base de datos orientada a documentos, ajuste natural para JSON/BSON FHIR.

🌌

Azure Cosmos DB

Soporte multimodelo (incluyendo SQL y MongoDB API) para persistencia FHIR global.
