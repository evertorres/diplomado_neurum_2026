Conclusión Teórica del Análisis de Usuarios y Funcionalidades (U-Fu):
La Matriz U-Fu es el punto de convergencia donde el perfil del usuario (User Analysis) se cruza con las operaciones de la ontología del dominio (Functional Analysis). A partir de aquí, el siguiente paso metodológico del TURF consiste en evaluar cómo se presentan visualmente estas funciones (Representación) y cómo se ejecutan paso a paso (Tareas).
