Ejemplo Clínico: Caso "Admitir un Paciente"

Desglose ontológico de los 4 componentes para un proceso asistencial y administrativo básico.

Meta (Goal) Objetivo

"Admitir y habilitar legalmente a un paciente en la institución hospitalaria"

Objetos Involucrados Datos / Entidades
  • Identificación: Tipo y número de documento único.
  • Fecha de nacimiento: Parámetro temporal del paciente.
  • Fecha actual: Marca de tiempo del evento de admisión.
  • Género / Sexo biológico: Relevante para asignación de sala y factores clínicos.
Limitantes (Constraints) Reglas de Negocio
  • Consistencia temporal: La fecha actual puede ser igual, pero nunca menor a la fecha de nacimiento.
  • Unicidad del registro: Solo se permite una historia clínica activa para un mismo documento de identidad en la base de datos institucional.
Operaciones (Operations) Acciones Concretas
  • Validación de fecha: Algoritmo de comprobación de formato y coherencia temporal.
  • Validación de identidad: Verificación de longitud, dígito de verificación y estructura.
  • Consulta de existencia: Búsqueda previa en el repositorio maestro de pacientes para evitar duplicados.
