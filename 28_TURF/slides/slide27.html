Estructura Jerárquica Ontológica:

Cada meta general se descompone en operaciones y sub-operaciones que actúan sobre objetos específicos bajo restricciones estrictas.

Los 3 Modelos de Better EHR:

Designer Model (lo programado) vs User Model (lo que el usuario requiere) vs Activity Model (lo que realmente se hace en la clínica). La usabilidad busca minimizar las discrepancias entre ellos.
