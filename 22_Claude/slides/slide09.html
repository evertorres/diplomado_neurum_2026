¿Qué son las Skills?

Módulos reutilizables de conocimiento, instrucciones (SKILL.md), scripts y recursos que extienden las habilidades nativas del modelo.

⚙️

Cómo usar una Skill

La IA detecta automáticamente cuándo la tarea requiere una skill disponible y consulta las instrucciones detalladas del archivo SKILL.md antes de actuar.

📦

Instalar Skills Externas

Clona o copia carpetas de skills a la ruta .agents/skills/ o la carpeta de configuración global para añadir superpoderes especializados a tu agente.

💡 Estructura Canónica de una Skill

mi_skill/ → SKILL.md (frontmatter YAML con name/description) + scripts/ + references/
