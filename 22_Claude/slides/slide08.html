Conectores en el Ecosistema Claude

Diapositiva 08 / 10

¿Qué son los Conectores?

Puentes de comunicación basados en Model Context Protocol (MCP) que permiten a Claude conectarse a bases de datos, APIs y herramientas externas de manera segura.

Instalación & Uso

Se instalan mediante npx o paquetes de la comunidad y se declaran en el archivo de configuración claude_desktop_config.json.

Múltiples Conectores

Claude puede invocar múltiples conectores a la vez (ej: leer datos de Postgres + buscar en Google Drive + enviar notificación a Slack en un solo turno).

// Ejemplo de configuración con múltiples conectores
{
  "mcpServers": {
    "database": { "command": "npx", "args": ["-y", "@modelcontextprotocol/server-postgres"] },
    "gdrive": { "command": "npx", "args": ["-y", "@modelcontextprotocol/server-gdrive"] },
    "slack": { "command": "npx", "args": ["-y", "@modelcontextprotocol/server-slack"] }
  }
}
