Para probar o para construir: Artefactos vs. Claude Code

Diapositiva 05 / 10

Los artefactos son perfectos para ideas rápidas y MVPs. Claude Code es el salto a productos de verdad.

CAPACIDAD 🟧 ARTEFACTO (Web / App) 💻 CLAUDE CODE (CLI / Agente)
Un archivo o varios Un solo archivo (HTML/SVG) Carpetas y subcarpetas complejas
Acceso a archivos locales (Disco) ❌ No (Sandbox) ✓ Sí (Lectura y edición directa)
Ejecuta comandos (git, npm, python) ❌ No ✓ Sí (Terminal agéntica)
Backend con base de datos ❌ No ✓ Sí (APIs, DBs, Microservicios)
Instalar librerías / paquetes Set limitado (CDNs) Cualquier paquete (npm, pip, cargo)
Ideal para Prototipos · MVPs rápidos Producto real en producción
🟧 ARTEFACTO

Prueba una idea en 2 minutos, comparte el link y valida antes de invertir. Probar barato.

💻 CLAUDE CODE

Proyecto con jerarquía, backend, git y librerías completas. Construir en serio.
