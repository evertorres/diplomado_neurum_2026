Diapositiva 04 / 10

¿Qué es Claude Code?

Una herramienta CLI (Command Line Interface) agéntica creada por Anthropic que vive directamente en tu terminal de comandos (Terminal / PowerShell / Bash).

¿Cómo trabaja Claude Code?

  1. Lee el repositorio: Entiende automáticamente la arquitectura de archivos.
  2. Edita directamente: Aplica parches y cambios precisos en código.
  3. Ejecuta comandos: Corre pruebas, linters, git y scripts.
  4. Auto-corrección: Lee logs de error de compilación y reintenta.
# Iniciar Claude Code en cualquier directorio
$ claude
