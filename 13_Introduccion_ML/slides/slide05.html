Terminologías para Ciencia de Datos y ML

Datos (Data)

"Hechos" extraídos de observaciones. Es la unidad básica de análisis en cualquier proyecto.

Características (Features)

Tipos de información o atributos que describen a cada dato (las variables explicativas de entrada).

Objetivo (Target / Label)

La variable o valor de salida que el modelo busca predecir o clasificar a partir de las características.
