Dividir el Dataset

Para evaluar de forma honesta el rendimiento de un modelo, debemos simular cómo se comportará ante datos nuevos (desconocidos). Dividimos las observaciones del dataset en tres subconjuntos excluyentes:

Entrenamiento / Training (60% - 80%)
Val (10% - 20%)
Test (10% - 20%)
1. Entrenamiento

El subconjunto principal sobre el cual el modelo aprenderá las relaciones y patrones.

2. Validación

Se utiliza para evaluar métricas durante el ajuste fino de hiperparámetros (evita sobreajuste).

3. Prueba / Testing

Datos completamente ocultos para evaluar la capacidad real de generalización del modelo.
