Componentes del Machine Learning

El aprendizaje automático involucra la integración de conceptos matemáticos, optimización y estadística organizados en tres componentes fundamentales:

1. Proceso de Decisión

Los pasos que realiza el modelo para retornar una predicción o respuesta (ŷ) al recibir los datos de entrada (X) y los parámetros internos del modelo.

2. Función de Error / Costo

Mide matemáticamente qué tan acertada fue la predicción del modelo en comparación con los valores reales conocidos (y). Cuantifica el error cometido.

3. Proceso de Actualización

Fase de optimización donde el algoritmo observa el error y actualiza los parámetros internos para minimizar el error en la siguiente iteración.
