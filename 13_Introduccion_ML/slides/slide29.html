Normalización de Datos

Los algoritmos de ML basados en distancias (como KNN o SVM) o optimización (descenso de gradiente) sufren sesgo si las variables tienen escalas muy diferentes (ej. Edad [0-100] vs Salario [Millones]).

Min-Max Normalization

Escala todas las características al rango estricto entre 0 y 1 (o -1 a 1).

x_norm = (x - x_min) / (x_max - x_min)

Estandarización (Z-Score)

Escala para centrar en media 0 y desviación estándar 1. Más robusto a outliers.
