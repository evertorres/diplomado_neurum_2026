¿Qué es el Aprendizaje por Refuerzo?

Un paradigma de Machine Learning diferente. En lugar de aprender a partir de ejemplos del pasado, el algoritmo (denominado "agente") aprende a comportarse interactuando de forma dinámica con un entorno.

🤝 Interacción con el entorno

El agente observa el estado actual, ejecuta una acción y recibe del entorno un nuevo estado y una recompensa.

🎯 Maximización de Recompensas

El objetivo primordial del agente es aprender qué acciones tomar para maximizar la recompensa acumulada a largo plazo.
