Exactitud (Accuracy)

Acierto Global

Proporción de predicciones correctas (tanto positivas como negativas) sobre el total de casos evaluados.

Exactitud = (VP + VN) / (VP + VN + FP + FN)

Precisión (Precision)

Calidad de Alerta

De todos los clasificados como positivos, ¿cuántos eran reales? Importante cuando el costo de un falso positivo es alto.

Precisión = VP / (VP + FP)

Sensibilidad (Recall)

Sensibilidad Clínica

De todos los casos reales positivos, ¿cuántos capturó el modelo? Vital cuando omitir un caso positivo (como una enfermedad) es crítico.

Sensibilidad = VP / (VP + FN)
