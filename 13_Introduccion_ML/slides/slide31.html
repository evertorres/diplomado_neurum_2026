Escoger el Estimador Adecuado

1. ¿Hay etiquetas en la variable de salida (y)?

Sí: Utilizar Aprendizaje Supervisado (Clasificación para variables categóricas, Regresión para continuas).
No: Utilizar Aprendizaje No Supervisado (Agrupamiento / Clustering).

2. Tamaño del Dataset

Para conjuntos de datos pequeños (menos de 100 mil registros), algoritmos lineales o basados en árboles son ideales.
Para conjuntos masivos, métodos de ensamble (XGBoost/LightGBM) o redes neuronales son preferibles.

3. Requisito de Interpretabilidad

Si es crítico explicar la razón de una decisión clínica (ej. Árboles, Regresión Logística).
Si se busca máxima precisión absoluta, se aceptan modelos de caja negra (Redes Profundas).
