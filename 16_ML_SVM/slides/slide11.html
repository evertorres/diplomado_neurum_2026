Tipos de Funciones Kernel

📏

Kernel Lineal

K(x, x') = x · x'

Para datos linealmente separables. El más simple y computacionalmente eficiente. Bueno para texto y datos de alta dimensionalidad.

📈

Kernel Polinomial

K(x, x') = (γx·x' + r)ᵈ

Modela relaciones polinomiales. El grado d controla la complejidad. Usado en procesamiento de lenguaje natural.

🔔

Kernel RBF (Gaussiano)

⭐ Más usado
K(x, x') = exp(−γ‖x−x'‖²)

Radial Basis Function. Muy flexible y potente. γ controla el "radio de influencia" de cada punto. Default en scikit-learn.

〰️

Kernel Sigmoide

K(x, x') = tanh(γx·x' + r)

Usado en redes neuronales de una capa. Análogo a la función de activación sigmoide. Útil para clasificación binaria no lineal.
