2️⃣ Búsqueda de hiperparámetros con GridSearch

from sklearn.model_selection import GridSearchCV

param_grid = {
    'C':      [0.1, 1, 10, 100],
    'gamma': ['scale', 'auto', 0.001, 0.01],
    'kernel':['rbf', 'linear']
}
gs = GridSearchCV(SVC(), param_grid, cv=5, scoring='f1')
gs.fit(X_train_sc, y_train)
print(gs.best_params_)

⚠️ Escalar es obligatorio

SVM es muy sensible a la escala de las características. Siempre usa StandardScaler antes de entrenar.

📦 Variantes en scikit-learn

  • SVC — Clasificación binaria / multiclase
  • SVR — Regresión con SVM
  • LinearSVC — Clasificación lineal rápida
  • OneClassSVM — Detección de anomalías

🚀 Multiclase

Por defecto usa OvO (One-vs-One). Para N clases se construyen N(N-1)/2 clasificadores binarios.
