Cross-Validation: El Proceso K-Fold

📋 ¿Cómo funciona K-Fold?

El training set se divide en K partes iguales (folds). En cada iteración, un fold es el conjunto de validación y los demás son de entrenamiento. Se repite K veces.

🔄 Proceso con K=5

Split 1
← validación
Split 2
← validación
Split 3
← validación
… y así hasta K=5. Resultado = promedio de 5 scores

📊 Ventajas sobre train/val simple

  • Todos los datos son usados para validación (una vez)
  • Estimación más robusta y estable del error
  • Detecta mejor el overfitting a una partición específica

Valor típico de K: 5 o 10. Con K=n se llama Leave-One-Out CV (LOOCV).
