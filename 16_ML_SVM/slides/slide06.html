SVM en el Panorama del ML Supervisado

Aprendizaje Supervisado

SVM es un algoritmo de aprendizaje supervisado. Aprende a partir de datos etiquetados (con clases conocidas) para clasificar nuevos ejemplos.

Clasificación y Regresión

Aunque se conoce como clasificador, SVM también resuelve problemas de regresión (SVR) y detección de anomalías (One-Class SVM).

Fundamento Matemático Sólido

A diferencia de otros modelos, SVM se basa en la teoría de optimización convexa, garantizando encontrar el óptimo global.
