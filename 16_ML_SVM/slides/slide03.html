Validación Cruzada: ¿Por qué la necesitamos?

⚠️ El Problema: Sobreajuste a los datos

Si usamos el mismo conjunto de datos para entrenar y evaluar el modelo, obtenemos una estimación demasiado optimista del rendimiento real.

💡 La Solución: Cross-Validation

Separamos el dataset en entrenamiento y test. Dentro del entrenamiento, usamos Cross-Validation para buscar los mejores hiperparámetros sin contaminar el test final.

✅ Flujo Correcto

  1. Separar Test data (nunca se toca hasta el final)
  2. Cross-Validation sobre Training data → mejores parámetros
  3. Reentrenar con todos los datos de training
  4. Evaluación final sobre Test data

🔑 Relevancia para SVM

En SVM, los hiperparámetros C y γ se deben seleccionar usando Cross-Validation — nunca mirando el test set.
