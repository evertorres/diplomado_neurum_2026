Caso de Estudio: SVM en Diagnóstico de Cáncer de Mama

Referencia: Breast Cancer Wisconsin Dataset — UCI Machine Learning Repository. Clasificación de tumores (maligno / benigno).

📋 Descripción del problema

  • 569 muestras de biopsias de tejido mamario
  • 30 características numéricas (radio, textura, perímetro, área, concavidad…)
  • Target: Maligno (M) / Benigno (B)
  • Reto: alta dimensionalidad relativa al número de muestras

🔧 Configuración del modelo

  • Kernel: RBF (Gaussiano)
  • C = 10, γ = 0.001 (GridSearchCV, 5-fold)
  • Preprocesamiento: StandardScaler
  • Split: 80% entrenamiento / 20% prueba

⚠️ Consideración Clínica

El Recall en malignos es la métrica crítica. Un falso negativo implica no detectar un cáncer real. SVM muestra excelente balance precisión-recall.
