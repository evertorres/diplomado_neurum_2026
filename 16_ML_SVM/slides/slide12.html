Hiperparámetros Clave: C y γ

Parámetro C — Regularización

Controla el equilibrio entre maximizar el margen y minimizar las violaciones de clasificación.

C pequeño
Margen grande, más errores permitidos. Underfitting
C grande
Margen pequeño, pocos errores. Overfitting
C = 0.01C = 1C = 100
↑ Margen grande↑ Overfitting

Parámetro γ — Radio del Kernel

Solo para kernels no lineales (RBF, sigmoide). Define el radio de influencia de cada punto de entrenamiento.

γ pequeño
Radio de influencia grande. Frontera suave. Underfitting
γ grande
Radio pequeño. Frontera compleja. Overfitting
γ = 0.001γ = 1γ = 100
↑ Frontera suave↑ Muy complejo

💡 Búsqueda de hiperparámetros: En la práctica se usa Grid Search o Random Search con validación cruzada para encontrar la combinación óptima de C y γ.
